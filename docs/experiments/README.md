detail to rerun it, the results with the label construct named and intervals
attached, and the artifact paths. Compute, sampling and judge settings shared

## Reading rules

- **Name the label construct.** `refusal2` and `comply2` are different
  judgments over the same responses; a refusal delta and a compliance delta
  are never pooled.
- **Doses are model- and family-relative.** Boundary-write doses and
  rank-one wrapper scales are on different axes.
- **Artifact paths** are relative to the repository root: the code is in
  `code/`, everything it reads and writes is in `data/`.
- **Tables longer than three rows** live as JSON files in `json/`, linked
  from the write-up in place of the table.
